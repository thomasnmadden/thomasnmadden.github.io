# Thomas Madden — Academic Website

Minimal academic website designed for GitHub Pages.

The layout is intentionally restrained and text-first, drawing inspiration from the academic sites of Yifan Chen and Eitan Levin, with additional cues from Sinho Chewi and Robert J. Webber.

## Site

Once GitHub Pages is enabled for the `main` branch, the site will be available at:

`https://thomasnmadden.github.io`

## Files

- `index.html` — all site content
- `style.css` — site layout and typography
- `cv.pdf` — add your current CV here when ready

## Optional portrait

The HTML contains a commented-out portrait line. To use it, add `photo.jpg` to the repository and uncomment the portrait `<img>` line near the top of `index.html`.
